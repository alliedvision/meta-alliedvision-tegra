# Allied Vision tegra bsp layer

Allied Vision camera support for NVIDIA Jetson systems. 

Compatible systems:
- Jetson Orin Nano DevKit with 2 Alvium CSI2 cameras (jetson-orin-nano-devkit-alvium-nvme)

## Dependencies
This layer depends on:

URI: git://git.openembedded.org/openembedded-core 
branch: scarthgap

URI: https://github.com/OE4T/meta-tegra.git
branch: scarthgap

URI: https://github.com/alliedvision/meta-alliedvision.git
branch: scarthgap

## Reporting issues

Please use the github issues section of meta-alliedvision-tegra for reporting build or runtime issue. When reporting an issue please include following information about your environment:
- Camera model and firmware version
- Host hardware information (SoC, Carrier)


Alternatively you can you write an email to the Allied Vision support: support@alliedvision.com
